# Changelog

All notable changes made to the Hope Hands Charity Foundation website are documented here.

- Added responsive CSS media queries for desktop, tablet and mobile devices.
- Added responsive navigation with a mobile hamburger menu.
- Added hover and active interaction effects for navigation links, buttons and social links.
- Added keyboard focus indicators for improved accessibility.
- Added responsive image versions for the Volunteers and Donation sections.
- Added `srcset` and `sizes` attributes to support responsive image loading.
- Added automatic copyright year using JavaScript.
- Added enquiry form confirmation messages.
- Added contact form confirmation messages.
- Added `README.md` project documentation.
- Added `CHANGELOG.md` to document project changes.

- Improved website layout for different screen sizes.

- Improved form accessibility and user interaction.
