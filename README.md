# Hope Hands Charity Foundation

## Project Overview

Hope Hands Charity Foundation is a fictional charity website created as part of a web development project. The website provides information about the organisation, its services, volunteering opportunities, and ways to make enquiries or contact the foundation.

## Purpose of the Website

The purpose of the website is to provide a clear, accessible and responsive online presence for a fictional charity organisation. It allows visitors to learn about Hope Hands, view its services, and submit enquiries or contact messages.

## Website Pages

- **Home (`index.html`)** – Introduces Hope Hands Charity Foundation and highlights how the organisation helps the community.
- **About (`about.html`)** – Provides information about the fictional organisation, its mission and values.
- **Services (`services.html`)** – Describes the fictional services and support programmes offered.
- **Enquiry (`enquiry.html`)** – Allows visitors to submit an enquiry through an online form.
- **Contact (`contact.html`)** – Provides contact information, a map and a contact form.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
- Visual Studio Code

## Responsive Design

The website uses CSS media queries and responsive layouts to support:

- Desktop devices
- Tablet devices
- Mobile devices

Responsive images are also implemented using `srcset` and `sizes` so that suitable image sizes can be selected for different screen widths.

## JavaScript Features

JavaScript is used for:

- Mobile navigation menu
- Automatic copyright year
- Enquiry form confirmation message
- Contact form confirmation message

## Accessibility

The website includes:

- Descriptive alternative text for images
- Labels for form fields
- Keyboard focus indicators
- Clear navigation
- Responsive layouts

## Images and Content

The website uses fictional content created for educational purposes. Images are used to support the visual design and communication of the website.
